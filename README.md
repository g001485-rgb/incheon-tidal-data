# 인천 바다 조류 예측 자료 (비공식 가공본)

인천 어업인용 앱에서 조류 화면을 빠르게 보여 주려고, **국립해양조사원 해양빅데이터의 수치조류도 예측 유향·유속**을
미리 받아 정적 파일로 만든 것입니다. 정부 기관이 운영하는 서비스가 아니며, **예측값이라 실제 흐름과 다를 수 있어 참고용**입니다.

- 출처: 국립해양조사원(https://www.khoa.go.kr)
- 범위: 경도 124.4~127.0, 위도 36.9~38.1 (서해 인천 앞바다)
- 간격: 30분, 지금부터 약 48시간 앞까지. 2시간마다 자동으로 새로 만듭니다.
- 파일: `index.json`(장면 목록), `tc/{시각}/{크기}_{ix}_{iy}.json`(타일별 점: 위도, 경도, 유속 cm/s, 유향 도)

만드는 도구는 `tool/tidal_current_prefetch/`에 있습니다(인증키는 저장소 비밀 값으로만 쓰고 어디에도 기록하지 않습니다).
